# 人脸核身 / 生物识别登录增强（可行性调研）

- 状态：🔶设计中（2026-08-15 完成三路调研，方向与是否实施未决策）

## 背景

2026-08-15 就「是否给 Serenique 增加人脸核身 / 生物识别增强认证」派了三个 librarian 调研子代理（结论源自 `@librarian` 子代理报告，原始完整报告在会话中，本文只沉淀结论）。动机背景：单人自用、已有 WebAuthn Passkey（Face ID/Windows Hello），在探索是否需要/如何增加人脸登录作为补充。

## 调研结论（2026-08 口径）

1. **Passkey 平台生物识别本来就免费**：OS 级平台认证器（Face ID / Windows Hello）无需额外付费、广泛可用——「标准答案」成立，不需要自建人脸方案替代 Passkey。
2. **自托管人脸识别 + 活体检测（OSS 2025–2026 格局）**：存在可选 OSS 方案（适配单人 Bun+Hono 场景），但活体（liveness）是自托管的主要复杂度来源。
3. **中国云人脸核身 API**（阿里云/腾讯等，纯人脸比对 + 活体检测、不碰身份证档位）：单价约 **0.1–0.6 元/次**；单人自用（每年几十到几百次登录）免费额度基本够一年，付费年成本也在几十元以内。

## 待决策点（留给后续会话）

- 是否推进：若走云 API，成本低且含活体；若自托管，无外部依赖但要自己处理活体。
- 归属场景：人脸登录是替代 Passkey 还是兜底（Web 端无平台生物识别的设备 / CLI）？
- 若决定推进，需再补一轮详细调研（选型对比、SDK 集成、隐私边界）后写正式实施方案。
