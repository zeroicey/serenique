- 前置记录：`2026-08-16-moment-draft-cache.md`、`2026-08-08-moment-location.md`、`2026-08-05-moment-tags.md`

## 1. 背景与目标

当前写一条闪记要走「列表页 → 点「新建」→ 单独页 `/moment/create` 输入」两步。用户觉得多此一举，希望在**闪记列表页直接内嵌一个快速新建区**，省掉那一步。

**明确不做**：不删除独立新建页 `/moment/create`（页面保留不动），只是**优化列表页**，让常用路径少点一步。

## 2. 需求明细

对 `MomentList`（`components/moment-list.tsx`）做如下改动：

1. **去掉**第一行标签搜索栏旁的「新建」按钮（`Plus 新建`）。
2. **新增一行**：在标签搜索栏下面，放置一个输入框（简单优先，用 `textarea` 组件）。
3. 输入区需集成：选择当前位置、添加标签、上传文件（附件）等操作。
4. 布局与交互：
   - **(a) 视觉布局**：整体视觉上是一个框。最顶部是输入框；下方是工具栏——**左边**放位置、标签、上传文件的图标；**右边**放发送按钮。
   - **(b) 置顶效果**：该新建区需要置顶固定。原本列表顶部的标签搜索栏会随滚动下滑，现在要在顶部单独开一个 div 区域把新建区固定住，下方内容才正常滑动。

## 3. 复用与实现方向（待确认）

- 位置：复用 `MomentLocationPicker` + `formatLocationLabel`（`features/location`）
- 标签：复用 `TagPicker`（只选已有标签，`features/tag`）
- 附件：复用 `MomentCreateAttachmentGrid`（`MediaFile[]`）
- 提交：复用 `useCreateMomentWithMedia`
- 草稿：复用 `useMomentDraftStore`（zustand persist）

## 4. 已确认决策（用户 2026-08-20 确认）

- [x] **置顶范围**：标签搜索栏 + 新建输入区**整块**一起固定置顶；下方列表正常滚动。
- [x] **发布后行为**：发送成功后**留在列表页**、清空输入框并就地刷新（新闪记出现在列表顶部），不跳转。
- [x] **独立页入口**：保留 `/moment/create`，在工具栏 3 个图标旁新增一个**放大按钮** → 进入独立页。
- [x] **内嵌区范围**：第一版**仅文字**（textarea + 发送）；位置/标签/上传三个图标**置灰占位**（不启用），完整能力走「放大按钮 → 独立页」。
- [x] **空态文案**：改为指引用户在顶部输入框记录。
- [x] **草稿**：复用 `useMomentDraftStore`（localStorage persist）缓存正文。
