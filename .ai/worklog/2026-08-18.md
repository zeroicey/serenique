# 2026-08-18

## AI 对话消息懒加载（后端分页 + Web + Flutter 全端）

**需求**：AI 对话会话变长后，`session_ready`/`session_switched` 一次性全量下发 + 前端全量渲染（每条 assistant 消息经 Streamdown/markdown 渲染）导致首屏慢、内存高。目标：初始只加载最新 N 条，向上滚动到顶部时再加载更早批次。

**方案（落盘 `.ai/requirements/2026-08-18-ai-message-lazy-load.md`）**：后端 `tailRenderMessages` 分页（全量转换后从尾部切片，天然保持 toolCall/toolResult 关联不断裂）+ WS 协议扩展（`load_more` c2s / `messages_loaded` s2c）+ `Conn.deliveredCount` per-connection 游标 + 前端 IntersectionObserver / ScrollController 触顶检测 + prepend 滚动位置补偿。

**后端（`services/api/src/modules/ai/`）**：

- `ai.service.ts`：新增 `tailRenderMessages(messages, limit, offset)` → `{ messages, total, hasMore }` + `INITIAL_PAGE_SIZE=20` / `MORE_PAGE_SIZE=30` 常量。`toRenderMessages` 全量纯函数不动（分页在 RenderMessage[] 层切片）
- `ai.types.ts`：`session_ready`/`session_switched` 增加 `totalMessageCount` + `hasMore`；新增 `load_more`（c2s，limit 可选）/ `messages_loaded`（s2c）
- `ai.handler.ts`：`Conn` 增加 `deliveredCount` 游标；`session_ready`/`session_switched`（`sessionPayload`）只发尾部 20 条 + 分页元信息；新增 `load_more` 分支按 `deliveredCount` 偏移取更早批次，累计 `deliveredCount`

**Web（`apps/web/src/features/ai/`）**：

- `lib/protocol.ts`：同步后端协议字段
- `store/ai-store.ts`：新增 `hasMoreMessages`/`loadingMore`/`totalMessages` + `loadMore()` action（防并发）；`messages_loaded` prepend；`session_ready`/`session_switched` 读新字段
- `components/message-list.tsx`：顶部哨兵 + `IntersectionObserver` 触发懒加载；`useLayoutEffect` 滚动锚定——通过比对 `messages[0]` 引用判断 prepend，prepend 时补偿 `scrollHeight` 增量，新消息/初始滚底；顶部「加载更早消息…」/「向上滚动加载更多」提示

**Flutter（`apps/mobile/lib/features/ai/`）**：

- `ai_protocol.dart`：新增 `ClientLoadMore`；`SessionReadyMessage`/`SessionSwitchedMessage` 增加 `totalMessageCount` + `hasMore`；新增 `MessagesLoadedMessage`
- `ai_controller.dart`：`AiState` 新增 `hasMoreMessages`/`loadingMore`/`totalMessages` + `loadMore()` action（防并发）；`MessagesLoaded` prepend；`SessionReady`/`SessionSwitched` 处理新字段
- `widgets/message_list.dart`：`ScrollController` 监听触顶（< 50px）触发 `loadMore`；`ref.listen` 检测 messages 头部增长（`prev.first != next.first`）判定 prepend，记录 `maxScrollExtent` 增量做位置补偿；顶部加载指示项（CircularProgressIndicator / "向上滚动加载更多"）

**坑 / 对下一次会话的提示**

- ⚠️ 分页必须在 `RenderMessage[]` 层切片，不能在 `AgentMessage[]` 层——toolResult 不产生独立 RenderMessage（被关联进 assistant 的 toolCalls），从尾部切片天然保持 turn 完整性，在原始消息层切片会拆散 toolCall/toolResult
- ⚠️ 游标 per-connection（`Conn.deliveredCount`）：多标签页同会话各自独立分页互不干扰，切会话/建新会话必须重置（`sessionPayload` 每次赋值 `deliveredCount = tail.messages.length`）
- ⚠️ Web `useLayoutEffect` 滚动锚定合并成单个 effect，避免 prepend 补偿与新消息滚底两个 effect 互相打架导致抖动；通过 `messages[0]` 引用变化区分 prepend vs 尾部追加
- ⚠️ Flutter `ref.listen` 检测 prepend 比 Web 复杂：需比对 `prev.first != next.first`，且 postFrame 回调里读 `maxScrollExtent` 差值补偿，`_appendingOlder` flag 防止新消息滚底 effect 在 prepend 期间误触发
- ⚠️ 测试 JSON fixture 改协议字段后必须同步更新：Flutter `session_ready` 测试 JSON 没带 `totalMessageCount` 导致默认 0 vs 期望 1 失败；所有直接构造 `AiState` 的测试都要补 3 个新必填字段
- ⚠️ 既有 biome lint 报错（habit 模块 import 顺序）是历史遗留，非本次改动引入，本次改动文件单独 biome check 干净
