# 2026-08-21 — 对象存储迁移 R2 实施完成（生产切换）

**目标**：blob 文件（Moment 附件）从 hpcore 本地 volume 迁到 Cloudflare R2：仅自己可访问 + 自定义域名 CDN + 标准 S3 协议。需求文档：`.ai/requirements/2026-08-20-object-storage-r2.md`。

## 架构定稿（决策 D-029/D-032）

- **私桶 + Worker 网关直链**：R2 bucket `serenique`（APAC）永不公开（不启用 r2.dev、不绑 bucket 级自定义域名）；自定义域名 `s3.0icey.icu` 挂在 Worker `serenique-r2-gateway`（infra/r2-gateway/）上，HMAC 自签直链。
- **签名域**（HMAC-SHA256 hex，secret = `R2_ACCESS_SIGNING_SECRET`，API 与 Worker 双侧一致、固定向量单测锁定）：
  - 读 `GET/HEAD`：`HMAC(v1:{storagePath}:{expires})`，query e/s
  - 写 `PUT`：`HMAC(up:{storagePath}:{expires}:{contentLength})` + Worker 校验 Content-Length==size
- **客户端直传（关键决策 D-032）**：Bun 运行时 `node:tls.connect({socket})` 报 Invalid socket → 任何 http-proxy/undici 库在 Bun 下都无法经 mihomo CONNECT 隧道访问 R2（多轮探针证实：probe9/10/13 hang，probe14 TLS-ERR）。容器直连又被 fake-ip/墙住。**因此 API 零 R2 网络**：上传两步（POST /blobs/upload-url 签发 PUT 凭据 → 浏览器/移动端直连 s3.0icey.icu PUT → POST /blobs/confirm 去重落库）；读走 Worker 直链。
- S3 客户端 `@aws-sdk/client-s3` 仅用于迁移脚本/管理员工具（本机运行，无需代理）；未来迁腾讯 COS/阿里 OSS 同协议。

## 执行过程要点

1. **R2 侧**：bucket serenique 已存在（用户创建）；Worker 部署 + 绑定 `s3.0icey.icu`（Workers Custom Domains API 自动建 AAAA 100:: 记录）；`workers_dev=false` 关闭子域。

## 坑（踩过）

- ⚠️ **镜像加速器缓存 tag/digest**：digest pull 可能 422（加速器未同步），等一会或本机 `docker pull --platform linux/amd64` 再用 image ID save（multi-arch save 会缺层）传服务器 load。
- ⚠️ **Bun 无法经 HTTP CONNECT 代理访问 HTTPS**（node:tls {socket} 不兼容）→ 生产 API 对 R2 唯一可靠路径是「客户端直传 Worker」。
- ⚠️ 容器内以非 root（UID 10001）跑 bun 脚本会 EACCES 写 tempdir；root 容器 + TMPDIR=/tmp 才可。
- ⚠️ 回滚到 local 时 `createAccessLink` 直链分支必须绑定 `STORAGE_BACKEND==='r2'`（D-031，否则回滚期新本地上传发 R2 直链 404）。
- ⚠️ 前端直传上线后，浏览器/PWA 缓存旧 bundle 仍走旧 multipart（r2 下会失败/去重打表）→ 需硬刷新/重装 PWA 后再传。
- ⚠️ 迁移脚本 Body 不能用 Bun.file 流式（SDK hash 校验失败）→ `new Uint8Array(await file.arrayBuffer())`。

## 滚动重载修复（web + 移动端，commit 28b8060 / 决策 D-033）

**症状**：列表滑到很下面再滑回顶部，第一张图重新转圈加载（Web 与移动端都有）。

**双端不同根因**：

- **Web**：每次滚动/分页重渲染，useBlobAccessUrls 重新申请 access-link，后端每次签发带**新 expires 时间戳 → 新签名 → URL 变化** → `<img>` src 变 → 浏览器当新图片重新下载。
- **移动端**：`Image.network` 只走内存 ImageCache，列表图多/滑得远时早年图被 LRU 逐出 → 回看重新走网络；且 `blobAccessUrlProvider` 是 `autoDispose`，滚动销毁后 Future 重算。

**修复**（D-033 不变式：签名直链有效期内必须稳定复用同一 URL）：

- Web：`createBlobAccessLink` 加**会话级 URL 缓存**（blobId→{url,expiresAt}，有效期最后 60s 提前刷新），有效期内复用同一 URL → 浏览器本地 HTTP 缓存（Worker `private, max-age=300`）命中秒开。
- 移动端：`blobAccessUrlProvider` 去掉 autoDispose（keepAlive）+ 图片改用 **`cached_network_image`（磁盘缓存）**。
- 已提交（28b8060）并部署：Web 上 CF Pages、iOS 重新装机（22.2MB）。两个平台均已验证秒开。
