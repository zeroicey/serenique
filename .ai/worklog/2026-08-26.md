### API 改造（services/api）

- 新增 OIDC 登录链路：`GET /api/auth/oidc/url`（服务端生成 state/nonce/S256 PKCE 登录态，内存 Map 10min TTL 一次性消费）+ `POST /api/auth/oidc/callback`（openid-client 完成授权码交换 + ID Token 验签，sub 映射 users 行后发原有 HMAC session cookie）
- `upsertOidcUser` 三分支：oidcSub 精确命中复用 → 绑定现有未绑定唯一行（个人信息不丢）→ 空表新建；并发冲突按 oidcSub 重查兜底
- 删除整套 WebAuthn：ceremony 端点、challenge Map、SETUP_TOKEN 门禁、bootstrap-user.ts、fail-closed users 空表断言、登录节流；`@simplewebauthn/server` 依赖移除
- env 变更：退役 `WEBAUTHN_*`/`SETUP_TOKEN`；新增 `OIDC_ISSUER/CLIENT_ID/CLIENT_SECRET/REDIRECT_URI`；生产 fail-closed = SESSION_SECRET + OIDC 四元组齐备
- Origin 白名单收敛到 `shared/origins.ts`（CSRF 中间件 + AI WS 门禁共用）：CORS_ORIGIN + OIDC_REDIRECT_URI origin + dev 端口兜底
- 会话 TTL 默认 30 天 → **3 天**（决策④）；`passkey_credentials` 表保留未删（防 drizzle-kit 生成 DROP，Phase 3 归档）
- 迁移 `0019_add_users_oidc_sub.sql`：users 加 oidc_sub text UNIQUE

### Web 改造（apps/web）

- API token 管理页原样保留（Mobile/CLI 存量通路不动，决策①）
