### Phase 2：移动端 OIDC 登录（2026-08-26 完成上线验收）

- 架构：App 拉起系统浏览器（flutter_web_auth_2，ASWebAuthenticationSession/Custom Tabs）→ 服务端生成授权 URL（`GET /api/auth/oidc/url?target=mobile` 用 `serenique://auth/callback` 自定义 scheme 回调）→ 回调查询串原样透传给 API 换会话 cookie → **用 cookie 铸一把长期 Bearer token 存 Keychain**（「认证中心管人，API token 管机器」，不受 3 天会话 TTL 影响）；旧令牌粘贴入口保留兜底
- ⚠️ 坑①：授权请求的 redirect_uri 必须按客户端区分——服务端登录态记录实际 redirectUri，交换时严格一致；否则 Pocket ID 会把用户送去 Web 端并消费掉 state（首测「跳到 Web 端登录成功」即此因）。修复：`?target=mobile` + env `OIDC_MOBILE_REDIRECT_URI`
- ⚠️ 坑②：Set-Cookie 取出的裸值拼回请求时必须带完整名值对 `Cookie: serenique_session=...`，只发裸值中间件匹配不到 → 401「未认证或登录已过期」（日志特征：callback 200 紧跟 POST /api/tokens 401）
- 平台接线：iOS Info.plist CFBundleURLTypes + Android intent-filter（singleTask）；**custom scheme 不需要 Associated Domains**——Passkey ceremony 在系统浏览器的 auth.zeroicey.me 完成，免费签名即可用
- 验收：iOS release 编译通过 + 真机端到端登录成功；Android 本机无 SDK 未验证（仅 Manifest 声明改动）；用户确认 OK
