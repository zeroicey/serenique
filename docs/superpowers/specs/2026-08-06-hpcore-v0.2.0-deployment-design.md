## 目标

1. 将 serenique 升级到 v0.2.0（含 moment 评论、diary by-date、MCP 新工具等，`services/api`/`services/mcp` 自 v0.1.0 以来的全部改动）。

- **hpcore**（Arch Linux，`ssh hpcore`，用户 oicey）：serenique 容器 `zeroicey/serenique-{api,mcp}:latest` = v0.1.0（Aug 5），healthy。API 监听 `127.0.0.1` + `10.126.126.2:3000`；MCP 监听 `3002→3001`（3001 被 vocechat 占用）。
- **frpc**（hpcore，systemd 用户服务 `frpc-serenique`，linger 已开）：`/home/oicey/apps/frp/conf/frpc-serenique.toml` 指向 `serverAddr=10.126.126.5:7000`，代理 `serenique-api`：`localIP=127.0.0.1, localPort=8081, remotePort=18081`。**8081 是旧项目端口，已无服务** → 公网 `api.zeroicey.me` 返回 502。
- **hpazure**（Ubuntu 22.04，`ssh hpazure`，用户 zeroicey，公网 104.208.114.194，EasyTier IP 10.126.126.5）：
  - `frps`（systemd `frps.service`）：`bindAddr=10.126.126.5:7000`，`proxyBindAddr=127.0.0.1`，token 认证 + TLS。无需改动。
  - `caddy`（`/etc/caddy/Caddyfile`）：`api.zeroicey.me → reverse_proxy 127.0.0.1:18081`。DNS 已指向 hpazure。无需改动。
- **Docker Hub**：`latest`=v0.1.0（Aug 5）；`main` tag 更新（Aug 6）。发布走 `v*` tag → 出 `latest`+`0.2.0`+`v0.2.0`。
- **数据库**（hpcore postgres:16 容器，库 serenique）：8 条迁移已应用，7 张表；本地有第 9 条 `0008_bitter_living_mummy.sql`（建 `moment_comments`）**未应用**。journal `when=1785992254001`。

## 目标架构

```
公网 HTTPS ──> api.zeroicey.me (104.208.114.194 = hpazure)
                ├─ Caddy (443, 自动 TLS) → reverse_proxy 127.0.0.1:18081
                └─ frps (7000, EasyTier 10.126.126.5) ←── frp 隧道 ──> hpcore:3000 (serenique-api)
```

唯一链路改动：hpcore 上 frpc `localPort: 8081 → 3000`。

## 执行步骤

### Phase 0 — 发布 v0.2.0（本地）
1. 提交待定改动（`.ai/` 文档 + AGENTS.md + 本设计文档）。
2. 发布前验证：`bun run typecheck` + `cd services/api && bun test`。
3. `git push origin main` → docker-publish 出 `main` tag。
4. `git tag -a v0.2.0 && git push origin v0.2.0` → 出 `latest`/`0.2.0`/`v0.2.0` + CLI Release。
5. 等待两个 workflow 成功。

### Phase 1 — hpcore 升级容器 + 迁移
1. `cd /srv/compose/serenique && docker compose pull`。
2. 传 `0008_bitter_living_mummy.sql` 到服务器；`docker exec -i postgres psql -U serenique -d serenique < 0008.sql`。
3. 记入 `drizzle.__drizzle_migrations`（`sha256(整文件).hex`，`when=1785992254001`）。
4. `docker compose up -d` 重建容器。
5. 验证 `/health` 200、模块列表、moment 评论路由。

### Phase 2 — hpcore 修 frpc 隧道
1. 编辑 `/home/oicey/apps/frp/conf/frpc-serenique.toml`：`localPort = 3000`，更新注释。
2. `systemctl --user restart frpc-serenique`。
3. 在 hpazure 验证 `curl http://127.0.0.1:18081/health`。

### Phase 3 — 端到端验证
1. `curl https://api.zeroicey.me/health` → 200。
2. `curl https://api.zeroicey.me/` → modules: diary/moment/blob/task/event。
3. HTTPS 建一条 diary → 内网 CLI 读到，确认读写贯通。
4. 检查 Caddy 日志无错误、TLS 证书正常。

## 回滚方案

- 镜像：compose 临时改 `image: zeroicey/serenique-api:v0.1.0` + `up -d`（v0.1.0 仍在 Docker Hub）。
- DB：0008 仅新增空表，`DROP TABLE moment_comments` 即可回滚。
- 隧道：`localPort` 改回 8081。

## 安全备注

API 目前**无鉴权**，`api.zeroicey.me` 公网公开后任何人可读写。后续建议（本次不做）：
1. Caddy 加 basic-auth / IP 白名单。
2. API 加 token 鉴权（涉及 CLI/Web/MCP 契约联动）。
